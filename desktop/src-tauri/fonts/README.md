# Bundled PDF fonts

These fonts are compiled into the app and used to typeset text-based files. Only
the glyphs a document uses are kept in each PDF.

| Font | Files | Licence |
|---|---|---|
| Liberation Sans 2 | `LiberationSans-*.ttf` | SIL Open Font License 1.1 |
| JetBrains Mono | `JetBrainsMono-*.ttf` | SIL Open Font License 1.1 |

The SIL Open Font License allows bundling and embedding the fonts in software and
documents: https://openfontlicense.org
