# Design system

Folio is a quiet utility inspired by the alignment and hierarchy of a well-organized file workspace. The task leads the page; no marketing hero or invented proof. The user selected a light public interface and direct implementation. Impeccable's launcher and concept seed were attempted but unavailable; the references guide the manual implementation.

Warm off-white background, white work surface, deep forest text, muted sage accents and a saturated forest-green action color. Inter is self-hosted for body and display type. Use generous outer margins, compact queue rows, 14px surface corners, thin separators and distinct focus outlines. A responsive two-column workspace contains the upload/queue area and output settings, becoming a single column on mobile. Compact format chips use consistent Lucide icons. A typographic wordmark and a small geometric file-transform mark identify the product.

One authored entrance reveals the work surface; reduced motion disables it. All controls have visible focus, hover, busy, disabled and error states. Conversion progress reports actual completed files, and the active file is indeterminate. No fabricated conversion percentages.
